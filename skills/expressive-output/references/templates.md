# 输出模板

所有模板共享同一个骨架：**一句话结论 → 读者最常找的东西 → 展开 → 原文依据 → 存疑**。按读者删减，不要按内容多少删减。

## 目录

1. 会议纪要（完整版）
2. 给决策者的简报
3. 只要待办
4. 讲座 / 课程笔记
5. 访谈 / 播客整理
6. 视频内容摘要
7. 文档 / 报告速读

---

## 1. 会议纪要（完整版）

见 SKILL.md 第 4 步。示例：`examples/demo-meeting/minutes.md`。

## 2. 给决策者的简报（≤ 150 字 + 一张表）

```markdown
**结论**：<一句话>
**要你定**：<事项>，<选项 A / B 及各自代价>，<最晚何时>
**风险**：<一条，带数字>

| 事项 | 状态 | 负责人 | 时间 |
```

不要写过程。决策者需要原因时，会去看完整纪要。

## 3. 只要待办

```markdown
| 谁 | 做什么（动词开头） | 截止 | 依赖 / 前提 | 原话 |
```

按人排序，同一个人的待办按截止时间排序。没有截止时间的写"未明确"，不要自己编。

## 4. 讲座 / 课程笔记（按幻灯片分节）

```markdown
# <课程名> 第 N 讲：<主题>
**这一讲解决什么问题**：<一句话>

## [mm:ss] 第 k 页 · <页标题>
- 核心观点：<讲者的话，不是 PPT 原文的复述>
- 例子 / 推导：<只保留能帮助理解的部分>
- 板书 / 图：<看图后的描述，或截图文件名>

## 容易错的地方
## 课后要做
```

PPT 上已有的文字不要原样照抄。笔记的价值在于讲者口头补充、PPT 上没有的内容。

## 5. 访谈 / 播客整理

```markdown
# <标题>：<受访者> 谈 <主题>
**最有信息量的三句话**（原话 + 时间戳）

## 话题 1：<用受访者的观点做标题，而不是"关于 X"这种名词短语>
<问题（一句）> → <回答要点，保留原话里有力的表达>
```

区分清楚"受访者说的"和"整理者归纳的"。

## 6. 视频内容摘要

```markdown
**一句话**：<视频讲了什么 / 发生了什么>
| 时间 | 画面 | 声音 / 字幕 | 要点 |
```

画面和声音分开写，方便发现"画面和台词说的不是一回事"（反讽、口误、字幕错误）。

## 7. 文档 / 报告速读

```markdown
**结论**：<作者的核心主张>
**证据**：<最关键的 2–3 个数字，注明页码>
**和你相关**：<针对读者的身份或问题>
**存疑**：<方法、样本、数据上的疑问>
```

## 写作自查（交付前逐条过）

- [ ] 第一句就是结论吗？
- [ ] 每条决定、待办都有依据（时间戳、页码）吗？
- [ ] 原文没有的信息有没有被补上？
- [ ] 数字、人名、日期都和来源对过了吗？（`coverage_check.py`）
- [ ] 有没有空话？（`coverage_check.py --lint`）
- [ ] 同一个概念有没有换着说法写？
- [ ] 删掉任意一段，读者会损失什么？说不出来就删掉。
