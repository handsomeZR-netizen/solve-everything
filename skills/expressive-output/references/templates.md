# 输出模板

所有模板共享同一个骨架：**一句话结论 → 读者最常找的东西 → 展开 → 原文依据 → 存疑 → 覆盖声明**。
根据读者来删减，而不是根据内容多少来删减。

## 目录

1. Agent 交接单
2. 短视频拆解（创作者视角）
3. 讲座 / 课程笔记
4. 访谈 / 播客整理
5. 文档速读
6. 给决策者的简报
7. 行动清单

---

## 1. Agent 交接单（给下一个 agent 或者接手的人）

示例：`examples/short-video/handoff.md`。

```markdown
# 输入处理交接单 · <范围>
**一句话**：<处理完了多少；有几条藏起来的关键信息；有几处矛盾需要人定>

## 需要人确认          ← 矛盾、缺失、权限问题
## 快速读取会漏掉的     ← 信息 | 位置（文件 + 时间戳/页码） | 为什么会漏
## 互证结果             ← 两路来源对不上的地方，以及以谁为准
## 处理范围             ← 文件 | 内容量 | 处理方式 | 覆盖
## 依据                 ← ledger.md · coverage.md · timeline.md · 截图 · 解包文件的路径
```

规则：

- 接手方要能**不重新处理**就判断哪些可以信，所以覆盖和存疑是必写项，不是可选项。
- 每条信息都写出处。接手方需要复查时，能直接跳到那一秒、那一页。
- 不要只交摘要。中间文件的路径一定要写上。

## 2. 短视频拆解（创作者视角）

来自作者做抖音音乐 MV 的工作流：拆别人的爆款，或者复盘自己的作品时用。

```markdown
# <视频标题> 拆解
**一句话**：<这条视频靠什么留住人>

| 时间 | 画面（含屏幕文字、闪现） | 声音（口播 / 歌词 / 音乐节点） | 作用 |
|---|---|---|---|
| 00:00–00:03 | <钩子画面> | <第一句> | 钩子：<悬念 / 反差 / 利益点> |

## 结构         ← 钩子 → 展开 → 转折 → 收尾 / 引导互动，各在第几秒
## 信息密度     ← 每 10 秒有几个新信息；画面信息和口播信息哪些重合、哪些只在一边出现
## 节奏         ← BPM；切镜头和节拍是否对齐（beats.json）；高潮落在第几秒
## 可复用的做法  ← 3 条，每条都能直接用到下一条视频上
```

画面和声音分开写，才能发现"画面在说一件事，台词在说另一件事"这样的设计，以及字幕错别字、口误。

## 3. 讲座 / 课程笔记（按画面分节）

```markdown
# <课程名> 第 N 讲：<主题>
**这一讲解决什么问题**：<一句话>

## [mm:ss] 第 k 页 · <页标题>
- 讲者的观点：<PPT 上没有、口头补充的内容>
- 例子 / 推导：<只留对理解有帮助的>
- 图：<看图后的描述，或者截图文件名>

## 容易错的地方
## 课后要做
```

不要把 PPT 上已有的文字原样抄一遍。笔记的价值在于讲者口头补充、PPT 上没有的东西。

## 4. 访谈 / 播客整理

```markdown
# <标题>：<嘉宾> 谈 <主题>
**信息量最大的三句话**（原话 + 时间戳）

## <用嘉宾的观点做标题，而不是"关于 X"这样的名词短语>
<问题，一句> → <回答要点，保留原话里有力的说法>
```

分清"嘉宾说的"和"整理者归纳的"。

## 5. 文档速读

```markdown
**结论**：<作者的核心主张>
**证据**：<最关键的 2–3 个数字，标出页码>
**藏着的**：<扫描页、附录、脚注、批注、隐藏表里的内容>
**和你有关的**：<针对读者身份或问题的部分>
**存疑**：<方法、样本、数据上的疑问；前后矛盾的地方>
```

## 6. 给决策者的简报（≤ 150 字 + 一张表）

```markdown
**结论**：<一句话>
**要你定**：<事项>，<选项 A / B 及各自代价>，<最晚什么时候>
**风险**：<一条，带数字>

| 事项 | 状态 | 负责 | 时间 |
```

不写过程。需要原因的话，他会去看完整版。

## 7. 行动清单

```markdown
| 谁 | 做什么（动词开头） | 截止 | 依赖 / 前提 | 依据 |
```

按人排序，同一个人的按截止时间排序。没有截止时间就写"未明确"。

## 写作自查

- [ ] 第一句就是结论吗？
- [ ] 藏着的信息和矛盾写出来了吗？
- [ ] 每条关键信息都有出处（时间戳 / 页码 / 文件）吗？
- [ ] 有没有把原文没有的东西补进去？
- [ ] 数字、人名、日期都和来源对过了吗？（`coverage_check.py`）
- [ ] 有没有空话？（`coverage_check.py --lint`）
- [ ] 写覆盖声明了吗？
- [ ] 删掉任意一段，读者会损失什么？说不出来就删掉。
